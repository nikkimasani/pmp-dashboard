# PMP Command Center

PMP Command Center is a focused study dashboard for preparing for the PMP exam. It keeps study planning, practice, progress, and reference material in a single browser-based workspace.

## What it covers

- Study plan and daily progress tracking.
- Practice questions, quizzes, and flashcards.
- Exam-readiness indicators and review priorities.
- Reference material for the current PMP exam content outline.

## Run locally

Open `index.html` in a modern browser, or deploy the repository as a static site.

## Notes

The dashboard is client-side and stores its working state in the browser. Export or back up the browser data before clearing site storage.
